## Схема базы данных

| Таблица | Назначение |
|---------|------------|
| `users` | user_id, user_name, user_password, login_count, work_time_total, last_date, is_admin |
| `settings_presets` | до 10 записей на пользователя: имя, hsk/list, speed, color, start_no, count, font_size, shuffle, tilt, visibility flags, created_at |
| `custom_word_lists` | list_id, user_id, name, card_count |
| `custom_words` | list_id, number, hieroglyph, pinyin, translation, phrase |
| `main_table_for_show` | HSK1–4 словарь (seed из hieroglyphs.py) |
| `app_stats` | total_app_opens, admin metrics |

**Дефолты для первого запуска** (из spec): HSK1, задержка 5 сек, зелёный цвет, старт с 1, 150 статей, шрифт 20.

**Формат автоимени пресета**: `N-dd-mm-yyyy-h:m` (N — порядковый номер входа).

## Экран №1 — «Начало работы»

### Блок 1: Вход
- Поля: имя, пароль
- Кнопки: **Войти**, **Регистрация**, **Войти, как гость**
- После успешного входа: скрыть форму входа, показать имя (зелёным), блок «История», счётчик входов «Вход №: N+1»
- Гость: имя «Гость», без сохранения настроек в БД (сессионные настройки в памяти)

### Блок 2: История настроек (до 10)
- Выпадающий список (иконка «свиток») с последними пресетами
- У каждого: иконки удалить / переименовать (макс. 15 символов)
- При выборе — разворачивает: группа слов, задержка (#.# от 0 до 10), цвет, старт No, число статей, размер шрифта
- Кнопка **Запуск** → переход на вкладку «Показ» с выбранными настройками

### Блок 3: Настройка новых параметров
- HSK1–4 (radio/checkbox — один уровень)
- **Загрузить список** + ссылка **Шаблон** (Excel)
- Слайдер скорости (0–10, шаг 0.1; при 10 → 0.2 сек — логика из spec)
- Radio: чёрный / зелёный / синий / красный
- Поле «число статей в показе»
- Слайдер «номер старта»
- Чекбоксы: **Перемешать**, **Наклон** (градусы)
- Live-preview иероглифа (размер/цвет/наклон)
- Кнопка **Сохранить настройки** → диалог с автоименем + поле своего имени

### Блок 4: Содержимое показа
- Чекбоксы: иероглиф, пиньинь, перевод, фраза

### Блок 5: Служебная информация
- Дата последнего входа, общее время занятий, название комплекта
- Кнопка **Выйти** → если настройки не сохранены, диалог «сохранить / отказаться / отмена»

## Экран №2 — «Показ»

- Слева вверху: название списка (мелко)
- По центру вверху: **ПАУЗА** (останавливает QTimer, сохраняет текущий индекс)
- Справа вверху: номер карточки
- Центр: иероглиф (крупно, цвет), пиньинь, перевод, фраза — по флагам видимости
- **Старт показа** → `QTimer` с интервалом из настроек, последовательная смена карточек
- **Закончить показ** → стоп, диалог сохранения настроек, возврат на «Начало работы»
- **ProgressBar** — `(current_index / total) * 100%`
- При паузе пользователь может перейти на «Начало работы», изменить настройки и вернуться — изменения применяются к текущей сессии

## Критические решения

1. **Пароли** — в spec нет требования хеширования; для совместимости с admin/admin оставляем plain text (как в прототипе), с возможностью добавить hash позже.
2. **Скорость показа** — slider 0–10 с шагом 0.1; mapping: `delay_sec = max(0.2, 10 - value * 0.98)` или таблица из spec (10 → 0.2 сек).
3. **Гость** — настройки только в RAM; при выходе не спрашивать сохранение.
4. **150 статей по умолчанию** — цикл по выбранному HSK-уровню с wrap-around или stop at end (уточнить при реализации: spec говорит «показываются без остановки по порядку» → циклический показ в пределах count).

## Риски

- **Объём UI**: много элементов на одной вкладке — потребуется аккуратная группировка (QGroupBox) и scroll area
- **Excel-формат**: нужна строгая валидация, иначе сломается slideshow
- **10 пресетов**: при сохранении 11-го — удалять самый старый (FIFO)
